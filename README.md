# Portfolio - Najet Zridette

Site vitrine qui présente mon parcours, mes projets et mes compétences.

Site en ligne : https://najetzridette.github.io/portfolio/

## Structure

```
portfolio/
├── index.html      Accueil : photo, accroche, lien vers le CV
├── projets.html    Mes projets
├── parcours.html   Ce que j'ai appris et mes expériences
├── contact.html    Coordonnées et formulaire de contact
├── style.css       Styles communs à toutes les pages
├── cv.pdf          Mon CV
└── images/
    └── photo.png   Ma photo
```

## Technologies

HTML et CSS, sans framework.

## Publication

Le site est publié avec GitHub Pages (Settings > Pages > Deploy from a branch, branche `main`, dossier racine).
Chaque `push` sur la branche `main` met automatiquement le site à jour.
